# Glossary

Part of [[Reference/Reference]].

| Term | Meaning |
| --- | --- |
| Vault | Human-readable map, rules, routing, current coordination, decisions, proposals and handoffs for one project |
| Root map | Project-name note routing readers to indexes and the read order |
| Canonical source | The one maintained authority for a particular kind of fact; other notes link it |
| Current truth | What is observed/verified now, with the actual delivery stage and evidence |
| Workstream | Distinct outcome/contract with an owner, boundary, Key files and finite acceptance |
| Key files | Exact sources and dependencies an assignment must read, plus what each proves |
| Job / SOP | Procedure for a recurring kind of work; it supplies no task authority by itself |
| Claim | Visible ownership of an exact overlapping file set or workstream |
| Shared-state lock | One-holder coordination for a resource separate file workspaces cannot isolate |
| Check-in | Truthful pre-edit report of reads, claim, locks, action and overlap |
| Living plan | Stable proposal note with current status, revision index and append-only saved reviews |
| Immutable revision | Complete frozen plan snapshot that later review/approval references without rewriting |
| Latest | Registry's explicit revision link, reconciled with living note and snapshot; never inferred recency |
| Accept | Reviewer verdict; not human approval |
| Approved | Exact revision explicitly authorized by the named human owner |
| Ambiguity table | Decision boundary, plausible drift, binding direction, owner/evidence and resolved/deferred/needs-decision state |
| Decision log | Settled cross-cutting choices with reasons and source references |
| Handoff | Meaningful result/checks, unfinished work, next owner/action and remaining authority |
| Orientation profile | Optional declarative source catalog; not authority, access control or full task context |
| Received / saved / applied | Correction understood / persisted with readback / used in a verified dependent output |
| Stop | Finite boundary of the current assignment; old instructions do not extend it |
