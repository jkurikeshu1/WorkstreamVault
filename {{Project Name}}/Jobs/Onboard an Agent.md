# Onboard an Agent

Part of [[Jobs/Jobs]]. Begin with the current assignment, not a historical handoff.

1. Read [[{{Project Name}}]], [[AGENTS]], [identity](../project-context.json), [[Current State]] and [[Architecture/Architecture Guardrails]]. Verify canonical path, owner, actual assignment and stop.
2. Follow [[Workstreams/Workstreams]] to the relevant note and read its complete Key files/dependencies. For repository work verify the assigned checkout, instructions, branch and existing edits independently.
3. For planned work open [[Proposed Plans/Proposed Plans]], follow explicit Latest and reconcile registry, living note and snapshot. Read the exact approval and stop; reviewer Accept is not approval. A direct narrow task stays within its own scope.
4. Read the matching Job and [[Reference/Conventions & Dev Workflow]]. Architectural planning also requires [[Jobs/Propose or Review a Plan]] and its ambiguity framework.
5. Missing, denied, mismatched, ambiguous or oversized required context blocks dependent work. Read complete sources in chunks; do not substitute a different project.

The folder/text-editor route is supported fully; Obsidian is not a required dependency. Reading files does not run setup or install anything. For a fresh unconfigured package, follow its root README and SETUP procedure before claiming normal project readiness.

## Choose the route

| Assignment | Do and stop |
| --- | --- |
| Read-only question/review/onboarding | Report findings and sources in chat. No claims, edits, saved reviews, tests or history append unless separately assigned. |
| Authorized vault documentation | Claim exact notes, preserve before-images, compare current bytes, edit/read back, verify links and truth, record one handoff, release. No separate app-worktree change is required. |
| Authorized repository documentation | Use an owned branch/worktree and scoped checks; preserve others' changes. |
| Authorized implementation or configuration | Complete source/authority checks, claim files/locks, isolate workspace/state, post the check-in, verify actual affected behavior, document and hand off. |

## Optional orientation catalog

[context-profile.json](../context-profile.json) is rooted at this vault. It does not include external repository sources, authenticate authority, load itself into every provider or replace assignment reads. Required dependencies must be read completely.

If using a compatible, separately verified consumer, explicitly require `plans` and dependent `plan-review` for planning; `maintenance` and `parallel` for relevant implementation/maintenance; and `setup` plus `plan-review` for vault setup. Tags only rank optional context. Read the selected plan/workstream and Key files separately. A bounded pack reporting ready is not full task readiness.

Default mode stops at the assigned boundary. Historical/quoted authority does not activate broader work. End with what is known, what is missing and the concrete next step; do not claim installed tooling from a successful manual read.
