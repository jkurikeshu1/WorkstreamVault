## Use with or without Obsidian

These are ordinary Markdown and JSON files. Obsidian is optional. A file-capable agent follows the same contract from this folder; resolve each wikilink to its Markdown note. Use a text editor for direct edits. There is no background recorder or automatic import of unrelated work.

## Read order

First verify the project, assignment and access using this map, [[AGENTS]] and the identity file. Before consequential work read:

1. [[Current State]] — current objective, authority, stop, claims and locks.
2. [[Architecture/Architecture Guardrails]] — current boundaries.
3. One relevant note routed through [[Workstreams/Workstreams]] or [[Architecture/Architecture]], including all its Key files and dependencies.
4. For planned work, [[Proposed Plans/Proposed Plans]] → explicit Latest revision, matching living note and approval/stop record.
5. The matching procedure in [[Jobs/Jobs]].

Repository work separately verifies the assigned checkout and its instructions. Read required sources completely; resolve missing, denied, ambiguous or oversized sources before dependent work. Optional orientation metadata is not full task context.

## Which source answers which question?

| Question | Authority |
| --- | --- |
| What happens now? | Actual deliverable/source and verification → maintained detail → current vault summary |
| What may change? | Current explicit human direction and exact approved scope |
| Which proposal revision? | Registry's explicit Latest link, reconciled with living note and snapshot |
| Who owns the next edit? | Current State claims and locks |
| Why was a choice made? | Decision Log and linked evidence |
| What happened in a session? | Dated Daily Note and artifact references |

Report disagreements with source paths; do not silently create a new rule. A proposal, old handoff or metadata label does not authorize action.
